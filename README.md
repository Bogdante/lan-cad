# САПР ЛВС — прототип редактора (Vue 3)

Прототип к главе 3 курсовой. Работает только в браузере, сервер не нужен.

## Как открыть
- Готовая версия: `dist/index.html` — открыть двойным щелчком в Chrome, Edge, Firefox или Яндекс Браузере.
- Режим разработки: `npm install`, затем `npm run dev` и открыть адрес, который покажет Vite.
- Пересобрать `dist/index.html`: `npm run build`.

## Сценарий демонстрации
1. «Пример: офис» — загружается условный офис из раздела 2.9.
2. Вкладка «Инструменты» → «Проложить все линии».
3. «Проверить» — ошибка R4 (не хватает портов) и предупреждение R8 (переполнен лоток TR-01).
4. Щёлкнуть по шкафу, добавить коммутатор на 48 портов → «Проверить» → предупреждение R5.
5. Добавить коммутатор на 24 порта; щёлкнуть по лотку у серверной, выбрать 200 × 50 → «Проверить» → нарушений нет.
6. «Сохранить JSON».
